# 餐饮宣传 / 预约 / 点餐 / 收银 微信 / 抖音小程序

一站式餐饮小程序系统，同步上线微信、抖音双端，集门店宣传、在线预约、扫码点餐、PC 收银于一体，一套后台统一管理，适合单店与连锁餐饮商家，支持源码私有化部署与二次开发。

小程序端可展示门店相册、菜品介绍、活动套餐，顾客线上预约桌位、预订包间；到店扫码自助点餐，支持堂食、外卖、自提，菜品规格选择、在线支付，订单实时推送后厨打印。配套 PC 收银台，支持线下收款、订单核销、退款操作。内置会员储值、积分、优惠券、团购营销，抖音短视频、直播挂载小程序引流拓客，打通公私域流量。

总后台统一维护菜品、桌台、订单、会员，自动生成营业报表，查看门店经营数据。前端基于 UniApp 开发，双端页面可自定义装修，UI、业务模块按需修改。部署文档齐全，上线周期短。帮助餐饮商家线上品牌宣传，减少人工成本，提升翻台率，沉淀私域会员，中餐、火锅、奶茶、烘焙门店均可使用。![Uploading 2025042311183073.png…]()
